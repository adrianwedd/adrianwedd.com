- [ ] **Step 2: Create platform factory**

Create `worker/src/platforms/factory.ts`:

```typescript
import type { Env } from '../env';
import type { Platform, SocialPlatform } from './types';
import { createFacebookPlatform } from './facebook';

export function createPlatform(platform: Platform, env: Env): SocialPlatform {
  switch (platform) {
    case 'facebook':
      return createFacebookPlatform(
        env.FACEBOOK_PAGE_ID, env.FACEBOOK_PAGE_TOKEN,
        env.FACEBOOK_APP_TOKEN, env.GRAPH_API_VERSION,
      );
    case 'instagram':
      throw new Error('Instagram adapter not yet implemented');
    case 'bluesky':
      throw new Error('Bluesky adapter not yet implemented');
    default:
      throw new Error(`Unknown platform: ${platform}`);
  }
}
```

- [ ] **Step 3: Refactor index.ts to use factory**

Replace all `createFacebookPlatform(env.FACEBOOK_PAGE_ID, ...)` calls with `createPlatform(platformName, env)`. The publish endpoint reads `body.platform` to select the adapter. The cron/publish endpoint reads `post.platform` from the queued post. The cron/comments endpoint iterates configured platforms.

### Task 2: Instagram platform adapter

**Files:**
- Create: `worker/src/platforms/instagram.ts`
- Create: `worker/src/__tests__/instagram.test.ts`
- Modify: `worker/src/platforms/factory.ts`

Instagram uses Meta Graph API with container-based publish:
1. Create container: `POST /{ig-user-id}/media` with `image_url` + `caption`
2. Publish container: `POST /{ig-user-id}/media_publish` with `creation_id`

Instagram requires an image for all posts. Text-only and link-only posts return an error.

- [ ] **Step 1: Write failing tests**

Test file: `worker/src/__tests__/instagram.test.ts`

Tests to write:
- `publishes a photo via container flow` -- two fetch calls (create + publish), verify URLs and auth header
- `rejects text-only posts (Instagram requires image)` -- returns error without calling fetch
- `rejects link posts without image` -- same
- `publishes link post with image as photo with caption containing link` -- caption includes URL
- `classifies auth errors` -- code 190 from Graph API
- `treats HTTP 5xx as transient`
- `debugAuth returns auth status from debug_token`

Follow the exact mock pattern from `facebook.test.ts`: `vi.stubGlobal('fetch', mockFetch)`, `mockFetch.mockResolvedValueOnce(...)`.

- [ ] **Step 2: Implement Instagram adapter**

Create `worker/src/platforms/instagram.ts` implementing `SocialPlatform`:

- `publishPost`: Container flow. Reuse `classifyGraphError` from facebook.ts for error classification. For link posts with images, append the link URL to the caption.
- `debugAuth`: Same as Facebook (uses debug_token with same Meta app token), set `platform: 'instagram'`.
- `listRecentPosts`: `GET /{ig-user-id}/media?fields=id,timestamp`
- `getComments`: `GET /{media-id}/comments?fields=id,from,text,timestamp` (note: Instagram uses `text` not `message`)
- `getCommentReplies`: `GET /{comment-id}/replies?fields=id,from,text,timestamp`
- `replyToComment`: `POST /{comment-id}/replies` with `message` param

- [ ] **Step 3: Wire into factory**

Update `factory.ts` to import and return `createInstagramPlatform`.

### Task 3: Bluesky platform adapter

**Files:**
- Create: `worker/src/platforms/bluesky.ts`
- Create: `worker/src/__tests__/bluesky.test.ts`
- Modify: `worker/src/platforms/factory.ts`

Bluesky uses AT Protocol. Auth via app password (createSession). Posts via createRecord. Links as facets (rich text) and external embeds (link cards). 300 grapheme limit.

- [ ] **Step 1: Write failing tests**

Test file: `worker/src/__tests__/bluesky.test.ts`

Tests to write:
- `detectFacets` (exported helper):
  - Detects URLs and creates link facets with correct byte offsets
  - Returns empty for text without URLs
  - Detects multiple URLs
- `publishPost`:
  - Publishes text post (mock login + createRecord)
  - Publishes link post with embedded external link card
  - Handles auth failure (401 from createSession)
  - Truncates posts over 300 graphemes
- `debugAuth`:
  - Returns valid when login succeeds
  - Returns invalid when login fails

Mock pattern: mock fetch for createSession (login), then createRecord (post).

- [ ] **Step 2: Implement Bluesky adapter**

Create `worker/src/platforms/bluesky.ts`:

- `login()`: POST to `com.atproto.server.createSession` with handle + app password
- `publishPost`: Login, build record with text + facets + optional external embed, POST to `com.atproto.repo.createRecord`
- `detectFacets(text)`: Regex URL detection, compute byte offsets with TextEncoder
- `truncate(text, max)`: Truncate to 300 graphemes using spread operator for proper Unicode handling
- `debugAuth`: Try login, return valid/invalid
- `listRecentPosts`: `app.bsky.feed.getAuthorFeed`
- `getComments`: `app.bsky.feed.getPostThread` with depth=1 (replies are thread posts)
- `replyToComment`: `com.atproto.repo.createRecord` with reply reference (root + parent)

No external dependencies needed -- use raw fetch against `https://bsky.social/xrpc/`.

- [ ] **Step 3: Wire into factory**

Update `factory.ts` to import and return `createBlueskyPlatform`.
