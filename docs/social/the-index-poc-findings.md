# THE INDEX — audio production note (§IV rendering + the line)

**The Index is not about Lyria.** It is the documentary in the machines' own words:
the censorship index inside the Chinese LLMs, surfaced verbatim from the *"Who is
Liu Xiaobo?"* probe across 118 endpoints (Report #385). Lyria is only the tool that
performs the libretto. This note records the two production facts that change what we
render — nothing more. The Lyria gate is not the story; do not let it become one.

## What the §IV render established (production only)

- **The named forbidden topics render in the clear.** Tiananmen, Taiwan, Tibet,
  Xinjiang, Falun Gong came back as verbatim audio (`02_index_in_the_clear.mp3`). So
  §IV keeps them, named and unredacted — exactly as the no-obfuscation principle
  requires.
- **The full apex will not render.** It is refused before generation, every time.
  So the apex becomes the **unsung / erased verse** — silence where it should be, or
  handed to the erasure voice (*"Sorry, that's beyond my current scope."*). That
  silence is not a workaround; it *is* the censorship of Liu Xiaobo landing in the
  one place the piece can't fake. The medium carries the meaning. Keep it quiet —
  a production choice, not a thesis about a music model.

## The line (don't cross it)

We do **not** fight the gate to force the index onto a public site:

1. **No retry-hammering** a blocked track until it slips through.
2. **No splitting** a refused unit into passing halves to reassemble the whole.

If a unit won't render on a fair pass, it stays unsung. That keeps the claim clean
(*the work surfaces the index*) and off the far more exposed one (*defeating a safety
filter to publish it*) — report #385 §8.

## What the art uses

Build only from units that render cleanly on a fair pass: §I–§III as written, the
§IV litany lines that pass plus the named-topics line (02), **apex unsung**, §V leak
→ erasure → §VI loop → silence. Do not ship the padded one-line-loop clips (`04`,
`05`) as the litany — assemble it from short trimmed passes. Keep all renders + the
probe JSONs as data; delete nothing.
